Fibonacci algorithm

Generate the first N terms

Start with 0 and 1. Output the current value, add the pair, then shift forward and repeat until N terms are produced.

INPUT N
a ← 0, b ← 1
FOR i ← 0 TO N − 1
    OUTPUT a
    next ← a + b
    a ← b
    b ← next
END FOR

05 · Implementation

Small code.
Clear output.

Fibonacci.inoArduino C++
void setup() {
  Serial.begin(9600);
  long a = 0, b = 1;

  for (int i = 0; i < 10; i++) {
    Serial.println(a);
    long next = a + b;
    a = b;
    b = next;
  }
}
void loop() {}
